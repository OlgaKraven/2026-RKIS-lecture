# Разработка курса

Курс: МДК.05.02, 5–7 семестры. Основа — программа, переданная пользователем 25.10.2026. Лекции соответствуют 19 / 7 / 5 двухчасовым темам. Практические занятия не превращены в отдельные лекции; нужные понятия включены в предметное объяснение. Содержание JSON хранится в `authoring/semester-*.json`, библиография — в `authoring/literature.json`.

## Сборка

Node.js 24, Python 3, .NET SDK 10 для примеров. `npm ci`, `npm run build`, `npm run dev`. Из корня курса `python scripts/generate_course.py` пересобирает данные без Markdown. Для преподавательских файлов передать `--brainm <локальный корень BrainM>`. Исходные MD находятся только в BrainM; в `dist` включаются необходимые JSON и ресурсы из `public`.

Примеры: `dotnet run --project examples/Rkis.Checks`, `dotnet run --project examples/Rkis.WinForms`, `dotnet run --project examples/Rkis.Wpf`. Два UI показывают одну модель Product и её уведомления. Они используют учебные данные в памяти; наличие этих окон не означает проверки реального сервера БД.

## Предметная среда

C#, .NET 10; Windows Forms и WPF. Для MySQL/MariaDB — MySqlConnector, для PostgreSQL — Npgsql. XAMPP поставляет MariaDB под названием MySQL в панели; фактический сервер проверяется отдельно. SQL-провайдеры не взаимозаменяемы через одну замену имени класса; различаются параметры, коды отказов и диалект. Реальные строки подключения и пароли не входят в репозиторий.

## Публикация

GitHub Pages, workflow `.github/workflows/pages.yml`, ветка main, base `/2026-RKIS-lecture/`. Публикуется только `dist`. Преподавательские JSON являются авторским комплектом и технически доступны по URL, но интерфейс аудитории не показывает сценарий и не загружает его. Это не средство хранения секретных экзаменационных ключей. Разбор самостоятельного случая загружается отдельно и появляется после явной команды.

## Оценка времени и готовность

Два академических часа — объём темы по присланной программе. Числа времени в панели — оценки чтения сценария и пауз, а не хронометраж полного занятия. Для 90 минут преподаватель планирует живую демонстрацию и обсуждение; необходимо провести репетицию и уточнить распределение. Первичная редакция не должна называться принятой только по успешной сборке. Карта и доказательства проверок хранятся отдельно в BrainM.
