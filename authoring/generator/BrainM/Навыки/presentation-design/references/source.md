# Источник и сохранённые ресурсы

Пользователь утвердил вариант 22 октября 2026 года: «Утверждаем этот вариант. Закрепи его как навык “Дизайн презентации”, сохрани прототип и все согласованные правила, опубликуй изменения».

Источник решения: [Проверь дизайн лекции](thread://01a16341-27bf-7a21-bc24-9a51243cb34b?hostId=local). Чтение чата для применения не требуется.

- `../assets/prototype-fragment.html` — точная копия последнего утверждённого `lecture-two-windows.html`, включая сравнение двух тем, титулы, вопрос, два текстовых экрана, «Запишите», самопроверку и режим двух окон.
- `../assets/preview.html` — автономный просмотр того же фрагмента. Единственная замена внутри фрагмента — внешний импорт Raleway заменён локальным `@font-face`; оболочка подключает локальный Lucide и ограничивает минимальную ширину сетки сравнения для автономного просмотра на 320 px. Исходный фрагмент не переписывается.
- `../assets/synergy-wordmark.jpg` — полный логотип из предоставленного пользователем изображения `2026-10-22 16.40.39.jpg`, сохранённый из встроенного ресурса утверждённого макета.
- `../assets/synergy-mark.png` — предоставленный пользователем файл «Лого выворотка вертикатьный.png», без переработки пикселей.
- `../assets/rhino-okfks.png` — носорог ОКФКС, уже встроенный в утверждённый прототип; ранее взят из сохранённого дизайна каталога. Для новых предметных сюжетов используется отдельный навык `lecture-rhino`.
- `../assets/vendor/raleway.woff2` — существующий встроенный шрифт из закреплённого дизайна каталога; `raleway-OFL.txt` — SIL Open Font License 1.1.
- `../assets/vendor/lucide-1.17.0.js`, `lucide-package.json`, `lucide-LICENSE` — копии уже закреплённой зависимости Lucide 1.17.0 и её лицензий. Повторное скачивание не выполнялось.

Логотип и изображения предоставлены как ресурсы проекта, а не как свободная библиотека для произвольного распространения. Контрольные суммы пакета хранятся в `BrainM/Проекты/Генератор лекций/dependencies.lock.json` от корня BrainM.

## Границы образца

Прототип на текущем Mac проверен в браузере: обе темы, расположение трёх строк преподавателя, серый шеврон, локальные изображения, переход к тексту и отсутствие переполнения слайдов. Автономный узкий экран проверен на ширине 320 px; сетка сравнения ограничена шириной окна. Два окна в образце изображены двумя областями одной страницы. Это не реализация синхронизации отдельных вкладок/экранов сайта.

Имя, должность и кафедра — заполнители, пользователь не передавал фактические данные преподавателя. В автономном образце состояние сохраняется только до перезагрузки; это не реализация хранилища профилей. Возврат в каталог — внутреннее представление демонстрации. Полноэкранная команда использует браузерный API и зависит от разрешений среды. Встроенный просмотр чата ограничивает полноэкранное API.

Публикация этого пакета в BrainM не меняет публичный сайт ОКФКС, учебное содержание или инфографику. На Windows, другом Mac, с реальным проектором и в печатном экспорте результат необходимо проверить отдельно.

Источник итоговых экранов — [версия a83aff1](https://github.com/OlgaKraven/2026-OKFKS-lecture/tree/a83aff10581dff0068241c488174d22179a6d4b2), опубликованная через Pages после успешных проверок. Ссылка на чат сообщает происхождение, для переноса не требуется.

`../assets/approved-preview.html` — автономная галерея итогового вида; изображения и точный слой CSS хранятся в `../assets/approved-2026-10-22/`. В manifest.json указаны исходный commit, размер окна, экран и SHA-256 каждого изображения. Снимки получены в Chromium из локальной копии той же опубликованной версии; учебные данные ОКФКС — примеры композиции, а не шаблон содержания другого курса. Галерея не исполняет интерфейс и не доказывает синхронизацию окон.

Исторические HTML выше сохранены побайтово и не являются главным образцом окончательной шапки, вопросного слайда, подвала и паспорта. Не возвращай из них удалённую строку контекста или команды анимации. Реализация интерфейса и его поведение сверяются с исходниками указанной версии сайта; CSS — слой оформления для этой реализации, не автономный движок.

Для опубликованной версии проверены 756 экранных макетов, семь PDF, определения и сложные схемы; каталог и слайд с определением открыты по публичному адресу без ошибок страницы. Это проверка текущего Mac/Chromium, а не подтверждение другого ОС или физического проектора.
