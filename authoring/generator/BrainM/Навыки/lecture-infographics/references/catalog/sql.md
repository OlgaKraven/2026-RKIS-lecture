# SQL и преобразования данных

Спецификации из пользовательского каталога 2.0. [Индекс групп](../catalog-index.md).

## DATA-01 — SQL JOIN — сопоставление строк и результат

**Категория:** Преобразования данных и SQL

**Назначение:** Объяснить условие соединения, кратность совпадений и происхождение каждой строки результата

**Нотация:** Две небольшие таблицы с ID строк и результирующая таблица; для условных JOIN — ON и линии сопоставления, для CROSS JOIN — все пары без ON. Учебное представление SQL, а не ER или диаграмма множеств

**Пример:** Клиенты и заказы: клиент с двумя заказами, клиент без заказов и заказ без сопоставленного клиента

**Анимация:** Подсветить пару строк и результат ON, затем добавить соответствующие строки результата; CROSS формирует все пары без проверки ON. Для внешнего соединения показать дополнение NULL. Источники и повторные совпадения сохраняются

**Сценарий:** Тип соединения INNER, LEFT, RIGHT, FULL или CROSS — вариант операции; наборы без совпадений, с несколькими совпадениями или NULL — входные данные. Путь определяется выбранными данными и условием

**Шаги:** 0 — таблицы и запрос; шаг — рассмотрение строки или пары и её вкладов; финал — полный результат. Однозначный порядок задаётся ORDER BY с достаточными ключами; иначе он помечается условным. «Назад» восстанавливает соответствия

## DATA-02 — Логические преобразования результата SQL-запроса

**Категория:** Преобразования данных и SQL

**Назначение:** Проследить фильтрацию строк, группировку, вычисление столбцов, устранение повторов и сортировку

**Нотация:** Текст конкретного запроса и последовательность промежуточных таблиц; логическая учебная модель выбранного SQL-диалекта, не физический план выполнения

**Пример:** Заказы → WHERE по статусу → GROUP BY по клиенту → сумма → HAVING → SELECT → ORDER BY → LIMIT

**Анимация:** Синхронно выделять часть запроса и соответствующее изменение таблицы: исключённые строки, состав группы, рассчитанное значение, итоговый порядок. Идентификаторы позволяют восстановить происхождение

**Сценарий:** Выбор запроса и набора данных: пустой результат, повторы, NULL, несколько групп. Это параметры вычисления; условие пересчитывается, а не выбирается нарисованная ветка

**Шаги:** 0 — исходные данные; шаг — логическая операция конкретного запроса с её результатом. Группу можно раскрыть; «Назад» возвращает предыдущую таблицу. Различия WITH, оконных функций и диалектов разбираются отдельно
