# Зависимости и перенос

Четыре обязательные зависимости [[Проекты/Генератор лекций/Проект генератора|генератора лекций]] закреплены файлами в Git. Машинный список и SHA-256 — в [dependencies.lock.json](dependencies.lock.json). Пути в нём считаются от корня репозитория, а не от домашней папки пользователя.

## 1. Носорог под дисциплину

Исходник: `BrainM/Навыки/lecture-rhino/`. Закреплена версия из commit `6e7d60a` BrainM с одобренной адаптацией для C++.

Переносится весь каталог: инструкция `SKILL.md`, метаданные `agents/openai.yaml`, исходный носорог, логотип, одобренный PNG C++, промпт C++ и сведения об источниках. Для применения достаточно прочитать [инструкцию](../../Навыки/lecture-rhino/SKILL.md). Персональная установка по [[Проекты/Навыки Codex/Список навыков|каталогу навыков]] нужна, если на новом устройстве требуется вызов через `$lecture-rhino`.

На устройстве отдельно требуется доступный инструмент генерации изображений. Наличие файлов навыка не подтверждает доступность генератора. Происхождение и хеши исходных иллюстраций записаны в [references/sources.md](../../Навыки/lecture-rhino/references/sources.md).

## 2. Дизайн каталога

Каталог `references/lecture-catalog/` содержит:

- `lecture-catalog-design.html` — неизменённый последний исходный фрагмент макета из чата; дата фиксации 22 октября 2026 по Москве;
- `preview.html` — отдельную страницу для самостоятельного просмотра того же фрагмента с локальными значками;
- четыре JPG с карточками в двух темах, мобильным видом и красными кнопками списка;
- `materials-qr-runtime.license.txt` — лицензии встроенного генератора QR;
- `vendor/` — закреплённый Lucide 1.17.0 для значков, сведения о пакете и его лицензию, а также OFL-лицензию встроенного шрифта Raleway.

CSS, JavaScript макета, Raleway WOFF2, PNG носорога и логотипа встроены в исходный HTML. Генератор QR `qrcode` 1.5.4 с `dijkstrajs` 1.0.3 тоже встроен и строит изображение локально. Lucide в исходной среде предоставлялся отдельно; самостоятельный просмотр подключает локальную копию той же версии 1.17.0.

Lucide получен из пакета `lucide@1.17.0` на unpkg; имя, версия, заголовок JS и лицензия сверены. Текст лицензии Raleway получен из официального репозитория Google Fonts, проверены название шрифта и SIL Open Font License 1.1. Точные URL и контрольные суммы полученных файлов включены в lock-файл.

Старые preview-обёртки из чата не являются зависимостью проекта: они подключали служебные скрипты среды через CDN. Открывай сохранённый `preview.html`. Ссылки на папку материалов в демонстрации ведут во внешнее хранилище; их открытие требует доступа к указанной папке, сам макет в неё ничего не отправляет.

### Ограничения макета

- Данные относятся к демонстрационному курсу ОКФКС. Семестры, названия и ссылки заменяются входными данными будущего генератора.
- Открытие лекции и экспорт PDF демонстрируют выбранное действие. Генерация лекций и PDF ещё не реализована.
- Сохранение состояния исходного фрагмента использует необязательный API среды чата. В самостоятельном просмотре изменения действуют до перезагрузки страницы. Постоянное хранение будущего приложения проектируется отдельно.
- Снимки внешнего вида подтверждают исходный образец, но не проверку будущего генератора и не запуск на другом устройстве.

## 3. Учебная инфографика

Полный каталог `BrainM/Навыки/lecture-infographics/`, версия 1.1.0: инструкция, метаданные и справочники. 82 вида — каталог выбора представления, не готовая библиотека компонентов. Навык задаёт подбор по содержанию слайда, единый дизайн, причинную анимацию, шаги и сценарии. [Порядок совместного применения](Навыки%20и%20процесс%20подготовки.md).

В ОКФКС реализация остаётся в репозитории курса; навыки и тексты MD — в BrainM. Доступность инструментов и результаты публичной проверки фиксируются отдельно от наличия файлов.

Публикация пакета не меняет сайт курса или инфографику.

## Как перенести

1. Получи актуальные файлы BrainM по [[Синхронизация с GitHub|памятке синхронизации]]. Проверь присутствие всего каталога этого проекта и `BrainM/Навыки/lecture-rhino/`, `BrainM/Навыки/lecture-infographics/`, `BrainM/Навыки/presentation-design/`.
2. Из корня репозитория запусти проверку файлов:

   ```bash
   python3 -B "BrainM/Проекты/Генератор лекций/verify_dependencies.py"
   ```

   На Windows используй `py -3 -B` вместо `python3 -B`. Проверке достаточно стандартной библиотеки Python 3; она не обращается к сети и не изменяет файлы.
3. Прочитай проектный [AGENTS.md](AGENTS.md) и инструкции трёх навыков. При необходимости установи персональную копию навыка, сохранив все вложенные каталоги, и проверь доступность инструмента изображений.
4. Открой `references/lecture-catalog/preview.html` и `BrainM/Навыки/presentation-design/assets/approved-preview.html` (второй путь от корня Git) в браузере. Сверь вид с JPG, переключение карточек/списка, поиск, материалы и профиль преподавателя.
5. При переносе в другой проект сохрани взаимное расположение `BrainM/Проекты/Генератор лекций/` и `BrainM/Навыки/lecture-rhino/`, `BrainM/Навыки/lecture-infographics/`, `BrainM/Навыки/presentation-design/`. Перенеси также применимые правила `.gitattributes`, чтобы Git не менял байты закреплённых ресурсов. В инструкциях нового проекта укажи чтение этого `AGENTS.md`. Для DOCX/PDF передай также `BrainM/Навыки/gost-formatting/` и правило его применения.

Копировать `_sources/`, личные пути Mac, старую папку визуализаций или весь каталог установленных навыков Codex не требуется.

## Проведённая проверка

22 октября 2026 на текущем Mac проверены все 18 закреплённых файлов, 25 локальных Markdown/Obsidian-ссылок и побайтовое совпадение исходного HTML с макетом из чата. В самостоятельную страницу включён тот же неизменённый фрагмент.

В Chromium проверены карточки и список на ширинах 320, 390 и 1024 px в светлой и тёмной темах: горизонтальной прокрутки нет. Работают 22 значка, поиск с фильтром, сохранение фильтров при смене вида, одинаковые красные кнопки открытия, окно предпросмотра, формирование QR и возврат фокуса после закрытия материалов. Ошибок JavaScript и запросов внешних HTTP-ресурсов при этой проверке не было. Снимки настольного и мобильного вида просмотрены. Запуск на Windows и другом устройстве в эту проверку не входил.

## Обновление зависимости

Проверь новый источник и изменения, сравни внешний вид и поведение, сохрани лицензии и ресурсы. Затем обнови `dependencies.lock.json` и запись о версии в этой заметке. Проверка сумм выявляет изменение файлов; она не определяет качество новой версии и не заменяет визуальный осмотр.

### Нормализация лицензии Raleway

При проверке Git-копии обнаружена разница только в окончаниях строк OFL: исходный CRLF (4497 байт, SHA-256 `7e946cf1171784d1015279e7dc35f827957a6b5d1f1f659ae0c98e5f5e37ed9b`) соответствует Git LF (4404 байта) после удаления CR перед LF. Текст лицензии не менялся. Lock теперь фиксирует фактический Git LF, чтобы проверка работала в чистом клоне с действующими атрибутами Git.

### Согласование Windows/macOS от 23 октября 2026

Содержательные уточнения процедурных задач из `14ebbc9` сохранены в `lecture-infographics`. Его расхождение с реестром на Windows было только преобразованием LF в CRLF при checkout. Источник закреплён по полному SHA этого коммита; текст не откатывался.

Для `presentation-design` сохранён шрифтовой профиль из `2a3ef2d`: Raleway 400/700/600 и моноширинная подстановка для кода. В реестр добавлены `references/typography.md`, `assets/typography/typography.css`, `raleway-cyrillic.woff2` и `raleway-OFL.txt`. Старые прототипы, галерея, снимки и лицензии сохранены; версия навыка остаётся 1.1.0, точная редакция определяется исходным коммитом и SHA-256 каждого файла.

Теперь закреплены все 78 файлов четырёх комплектов. Проверка обнаруживает также добавленные ресурсы, отсутствующие в lock. `.gitattributes` сохраняет точные байты навыков и референсов на Windows/macOS. На Windows все десять собственных персональных навыков совпадают с общими исходниками. Содержимое персональных установок Mac нужно проверить на самом Mac по [[Проекты/Навыки Codex/Два устройства и проверка навыков|памятке согласования]]. Совпадение файлов не заменяет проверку внешнего вида и поведения целевого курса.
